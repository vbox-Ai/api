feat(fl2): fulao2 信封 + 响应解密 + register-token 全通（业务接口部分完成）

本轮把 fl2 最硬的三层打通：

1) 请求信封（onRequest）
   KEY=base64Decode("euZN1Gg3JIwWOEWhmE7C4l5dSSRU34fyuPMXjtuoqVs=") 32B/AES-256
   payload = base64(IV) + "." + base64(AES-256-CBC(jsonEncode(map), KEY, IV))
   GET ?payload=… / POST form payload=…
   头：User-Agent "Fulao2/Android 2.40; <model>"、X-Info、Uuid、Authorization Bearer <token>
   坑：map["path"] 必须**不带前导斜杠** —— 带斜杠时服务端回 495 decrypt failure，
       极容易误判成"密钥不对"（r1 就是这个反例，r2 四维扫描定出来）

2) 响应解密（onResponse）
   vtag=响应头 X-VTag；h=MD5(vtag)；Key=utf8("db6f7f9e5d7a770e0e3497a7d7a077f5")；
   IV=utf8(h[8:24])；AES-256-CBC-decrypt64 → jsonDecode
   （asm 的 0x30 是 Smi 编码=24，与 Dart substring 越界必抛互证）

3) register/token（无需账号，uuid4 即注册）
   device_id / key=sha256("jav"+dev+"jav") / universal_id=base64(dev) / platform=Android
   → {"status":{"code":200},"response":{"token":…,"refresh":…,"expired":7200}}
