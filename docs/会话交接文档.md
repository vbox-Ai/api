## 四、已破解的全部加解密算法（核心资产）

### 1. 暮色主后端 6868（配置/域名/token 下发）

```
链路：chunked 去帧 → base64 → AES-128-CBC → 软 gzip → JSON
key = "8992d27bceae2962"      # 16 字符 ASCII（不是 hex！bytes.fromhex 会得到 8 字节报错）
iv  = "62233532ac9029c6"
gzip 尾部有瑕疵，必须 zlib.decompressobj(-15) 从第 10~16 字节偏移软解
```

- 解密器：`tools/_cap_final.py`
- 产物：`tools/_dec/box_api_splash.json`、`box_api_home_versionCode=101.json`
- **现状**：`/box/api/splash` 与 `/box/api/home` 已被服务端加固，返回 `{"code":400,"msg":"违规请求"}`。
  正确 `time`(13位毫秒)+`uuid`(32位hex) 也过不去。错误分支：缺头→`缺少请求头:xxx`，时间早→`请求已过期`，时间对→`违规请求`。
- **影响面**：不影响任何平台适配，因为 host 表已固化在 `PLATFORM_HOSTS`。

### 2. hdb 黄豆瓣

```
请求：AES key/iv 随机16字节 → RSA(服务端公钥) 包 key/iv → AES-CBC(业务JSON)
响应：RSA(客户端私钥) 解 key/iv → AES-128-CBC 解 data
```
- 服务端公钥 + 客户端私钥已内置在 `HdbAdapter`
- `film_id` 必须传字符串；`ltype` 必须匹配列表项 `belong`
- `dailyList` 的 `date` 是**必填**，缺了返回 `41000 参数错误`；当天无更新时列表天然为空 → 已实现回溯最多 7 天

### 3. mmav 猫咪AV

```
key = "IdTJq0HklpuI6mu8iB%OO@!vd^4K&uXW"     # 32 字符 → AES-256
iv  = "$0v@krH7V2" + response["suffix"]       # 固定串在前，动态 suffix 在后
data = base64 → AES-256-CBC → JSON
```
播放签名（wsSecret）：
```
expire   = now + 7200
wsSecret = md5( "D7hGKHnWThaECaQ3ji4XyAF3MfYKJ53M" + uri.path + expire )
→ url?wsSecret=xxx&wsTime=xxx&ip=xxx
```
- 解密器：`tools/_mmav_dec.py`，一键转储 `tools/mmav_dump.py`
- 详见 `docs/mmav协议详解.md`

### 5. hxsp 红杏

```
map  = 固定字段（appVersion=5.3 client=1 tenant=05 phoneIp=10.0.0.0
       matchid=4310ced81499c24b(全小写) m3=1 m2=a4a099fc3c66bf328caa4ce4d5268c0b
       token=JWT timestamp=13位毫秒 nonce=uuid4）+ 业务参数
```

### 6. hgsp 黄瓜

```
flowId = "//" + uuid4 + "/?Authorization=&Seq=...&X-Auth-Key=...&X-Auth-Nonce=<8位>&X-Auth-TimeStamp=<13位毫秒>&"
X-Auth-Sign = urlencode(base64(HMAC_SHA1("cuke@appSecret#Ten2020!0120", base64url(flowId))))
固定头：pkg=cuke0001 release=506 Ip=0.0.0.0 terminal=2 m2? X-Auth-Key=...

```

### 7. 4hu 4虎

```
业务响应：base64(- _ → + /) → AES-256-CBC
key = "22946bc50fd63164b79df55070a85a92"   # 32 字符 → 32 字节（不是 hex）
iv  = "kaixin1234567890"

CDN 反爬 ap-d 块（纯 XOR，无需执行 JS）：
key[i]   = int(data_k_hex[2i:2i+2], 16) ^ 0xA5
plain[i] = base64decode(blob)[i] ^ key[i % len(key)]
```
- 详见 `docs/4hu攻坚进展.md`

### 8. hjsq 海角社区（全链路已通，唯一需要解的是图片容器）

鉴权（无签名、无时间戳、无 nonce）：
```
X-User-Id    : "171299991201"                      # 静态硬编码
X-User-Token : SpUtil["token_hjsq"]                # 游客 token
信封：{"errorCode":0,"message":"","data":…}；GET 取 data，POST 取 response
```

视频（零破解，直链明文在详情里）：
```
attachments[category=video].remoteUrl → https://0ts10.….top/hjstore/video/…/xxx_preview.m3u8
HLS + AES-128：URI="enc_<attId>.key"（同目录，无需鉴权，16 字节）
video_time_length 单位秒
```

图片 `.jpg.txt`（自定义字母表 base64 → data URI → JPEG）：
```
自定义字母表 = "ABCD*EFGHIJKLMNOPQRSTUVWX#YZabcdefghijklmnopqrstuvwxyz1234567890"
              （libapp.so 偏移 651830；* 顶替 +、# 顶替 /，但位置被重排）
step1: 逐字符查表得 6-bit → 拼字节（表外字符忽略）
step2: 得 "data:image/jpeg;base64,XXXX"
step3: 取逗号后部分 → 标准 base64 解码 → JPEG

⚠ 两个致命细节：
   a) "#FE" 不是魔数头，**不能剥掉** —— 全文 %4==0，剥掉 3 字符后 %4==1 即对齐错
   b) 按标准表做 *→+ / #→/ 替换必然失败，字母表被重排过，必须整表查索引
```
- 详见 `docs/hjsq攻坚报告.md`
- 图片走 `localProxy` 实时解码，`vod_pic` 用 `http://127.0.0.1:9978/proxy?do=py&type=hjsq&url=<enc>`

## 五、关键踩坑清单（每个都真实踩过）

| # | 坑 | 现象 | 正解 |
|---|---|---|---|
| 1 | 空值请求头 | curl 丢弃 `user-key:` 空头 → 401「缺少用户码」 | 用 urllib（会发空值头），或手工构造 |
| 2 | key 当 hex | `b"8992d27bceae2962"` 用 `bytes.fromhex` → 8 字节 → `Invalid key size` | 16/32 字符的 key 直接 `.encode()` |
| 3 | IV 顺序 | mmav 的 IV 反过来也能解出「像明文」的乱码 | 必须 `常量 + suffix`，用明文首字符校验 |
| 4 | Python TLS | `hxapi.ruueyek.com` 报 `UNEXPECTED_EOF_WHILE_READING` | 改用 curl 子进程 |
| 5 | GCM 卡死 | `git push` 无输出挂起 | `-c credential.helper=` 置空 |
| 6 | 代理自停 | 所有请求返回 `000` | 重启 mihomo |
| 7 | 分页语义 | mmav `list-7-51-50.js` 返回空 | 中间数字是**页码**不是偏移 |
| 8 | 500 当路由存在 | 4hu 任意路径都 500「系统繁忙」 | 要用**随机路径对照**判断 |
| 9 | 挑战页兜底 | `scdn_apd=1` cookie 以为能绕过 | 实际要解 `ap-d` XOR 块 |
| 10 | 域名轮换 | 4hu 域名一直在变 | 跟随 302，缓存 5 分钟 |
| 11 | 根路径误判 | hjsq `/` 返回 nginx 欢迎页 → 被记为「未配置」 | 业务全在 `api2/` 前缀下，探 `/` 无意义 |
| 12 | 把密文头当魔数剥掉 | hjsq 图片 `#FE` 剥掉后解出乱码 | 先看 `len % 4`，对齐错就说明不该剥 |
| 13 | 字母表当简单替换 | `*`→`+`、`#`→`/` 替换后无魔数 | 整表**被重排过**，必须查索引而非替换 |
| 14 | 16 字符重复块误导 | 误判成周期密钥的零填充区 | 实际是 `data:image` 附近的结构重复 |
| 15 | 空节点当故障 | hjsq nodeId=900 返回空 | 看 `total`，`total=0` 是平台侧真空 |
| 16 | 漏看明文直链 | 想去 `POST api2/attachment` 换播放地址 | 视频 m3u8 **已在 detail 的 attachments 里** |
