### 推送配方（每次照抄）

```powershell
$d="C:\Users\Administrator\Downloads\vboxapp\_remote_api"; $tok="<vbox-Ai 的 PAT>"
$env:GIT_TERMINAL_PROMPT="0"; $env:GCM_INTERACTIVE="Never"

# 代理挂了先拉起（机器重启后 7890 常不在）
if(-not (Test-NetConnection 127.0.0.1 -Port 7890 -WarningAction SilentlyContinue).TcpTestSucceeded){
  Start-Process "C:\Program Files\Clash Verge\verge-mihomo.exe" `
    -ArgumentList @("-d","C:\Users\Administrator\Downloads\DPK\mihomo_run","-f","C:\Users\Administrator\Downloads\DPK\mihomo_run\config.yaml") -WindowStyle Hidden
  Start-Sleep 5
}
git -C $d remote set-url origin "https://vbox-Ai:$tok@github.com/vbox-Ai/api.git"
# pull 要重试：TLS "unexpected eof while reading" 很常见，3~4 次必有一次成功
for($i=1;$i -le 4;$i++){
  git -C $d -c http.sslBackend=openssl -c http.proxy=http://127.0.0.1:7890 -c credential.helper= pull --rebase origin main
  if($LASTEXITCODE -eq 0){break}; Start-Sleep 4
}
git -C $d -c http.sslBackend=openssl -c http.proxy=http://127.0.0.1:7890 -c credential.helper= push origin main
git -C $d remote set-url origin "https://github.com/vbox-Ai/api.git"   # 收尾还原，勿留 token
```

要点：
- **必须** `-c http.sslBackend=openssl`，否则 schannel 直接失败；
- 仓库有自动提交（`chore: bump config version to <日期>.<序号>`），pull 后本地常落后 1 个，属正常；
- 验证是否真推上去：`git ls-remote origin refs/heads/main` + `git cat-file -p origin/main:<文件>`（别只看本地 `origin/main` 缓存）；
- 用户给过两个 PAT：`ghp_s227…`（vbox-Ai，**有写权限**）、`ghp_BG74…`（hf805864818，**只读，push 会 403**）。

## 四、Flutter 客户端的关键事实（决定脚本怎么写）

从 `_vboxapp_repo` 读出来的，**每条都踩过坑**：

| # | 事实 | 后果 / 对策 |
|---|---|---|
| 1 | `PythonBridgeEngine.timeout = 20s` 是**整次调用**预算 | `homeContent` 不许联网（坑 #25）；重活要设截止时间 |
| 2 | **没有** `/proxy?do=py` 路由（只有 iOS 有） | 脚本里写 `127.0.0.1:18080/proxy?do=py…` 在 App 内必 404 → 封面全空 |
| 3 | 漫画阅读器支持 `data:` URL | 加密图片只能在 Python 侧解密后**内联 base64** |
| 4 | `coverFor` 会把 `http://` 升成 `https://` | 只支持 http 的图床会挂 |
| 5 | 图片 URL 支持 TVBox 后缀 `@Referer=…@User-Agent=…@X-VBox-SSL-Bypass=1` | 需要防盗链头时直接拼进 URL，不用代理 |
| 6 | `defaultProxy` 字段只存不用 | 别指望它开代理 |
| 7 | 平台脚本带缓存，按 platformKey 下载 | 改完必须让客户端刷新配置/清缓存才生效 |
| 8 | `categories.isEmpty` → 「未能解析到分类，请检查域名或网络」 | 分类永远要有兜底 |

## 九、下一步建议（按性价比）

1. **`insav`** —— 同款信封现成，只差域名；从盒子 API 的 `/box/api/home`（域名下发通道）解一次可全平台受益；

## 十、交付纪律（沿用）

- 适配器全部**单文件自包含**，运行时层（`_SSL_CTX` / `_vbox_proxy` / `_vbox_host` / `_vbox_opener`）必须内联；
- 内置域名**优先**，客户端注入的 `_vbox_effective_hosts` **仅作回退**（坑 #15）；
- 不留半残平台：四能力没打通就先不注册（`fl2` 即此状态）；
- 每次改动都要 `_smoke_standalone.py` 回归 + 重生成平台总表 + 文档记录，再推送。
