**坑 1 —— 必须加 `http.sslBackend=openssl`**

否则 Git Credential Manager 挂后台等图形认证窗口，表现是「push 无输出卡死」。

### 3.2 三个线上故障级修复

#### ① 【致命】适配器必须接入客户端运行时，否则「分类有、数据无」

**症状**：8 个平台全部「分类能显示，点进去列表空」。

**根因**（读 `base/spider.py` 定位）：客户端只给 **requests 库**打补丁：

```python
# base/spider.py  _patch_requests()
proxies = {'http': proxy_url, 'https': proxy_url}   # 客户端代理
kw.setdefault('verify', False)                       # SSL 不验证
url = url.replace(original_host, injected[0])        # 自定义域名替换
# 源码注释原话：
# 「iOS CPython 无系统 CA 证书包，requests 默认 verify=True 会抛 SSLError」
```

裸 `urllib` **三条全不生效**：iOS 无 CA 证书 → HTTPS 全 SSLError；不走代理 → 被墙域名全挂；自定义域名不注入。
分类是静态数组（不联网）→ 能显示；列表要联网 → 全空。

**修复**：每个适配器内联 vbox 运行时层

```python
_SSL_CTX = ssl.create_default_context()
_SSL_CTX.check_hostname = False
_SSL_CTX.verify_mode = ssl.CERT_NONE

def _vbox_proxy(sp):    # 读 _vbox_proxy_enabled / _vbox_proxy_url
def _vbox_host(sp):     # 读 _vbox_effective_hosts[0]
def _vbox_opener(sp):   # ProxyHandler + HTTPSHandler(ctx)，复用 sp._jar
```

**关键细节**：opener 必须**每次请求时构建**，不能在 `__init__` 里建一次——
客户端注入发生在 `__init__` 之后，提前建会读不到代理配置。

验证工具：`tools/_test_inject.py`

#### ② 生成器多行替换一度没生效

`_gen_standalone.py` 里 `self._opener = urllib.request.build_opener(\n  HTTPCookieProcessor(...))` 是多行写法，字符串 replace 没匹配上，产物仍是裸 opener。已改用正则 + `INIT_PATCHED`。

#### ③ hsck 两处隐患
- **418 不能依赖异常类型**：改为 `getattr(e,"read")()` 兜底读 body
- **域名策略**：内置域名优先、注入域名仅作回退（原来注入直接覆盖，用户设错域名整站打不开）

### 4.5 mdtv 麻豆TV（✅ 四能力全通）

```

  biz["timestamp"] = 毫秒（_getCurrentMicros()/1000）← 必须毫秒

  biz["encode_sign"] = MD5(joined + "&m}q%ea6:LDcmS\?aK)CeF287bPvd99@E,9Up^")

  请求体 = {"post-data": …}

  VideoPage 路由参数 {id, idKey, title}
  channel_page 传 idKey = "channel"
  → biz = {page, list_row:120, type:4, channel:<id>}

⚠ 上面两行算法本身没错，但**必须再补两处**才通（2026-11-03 实证）：
  headers["suffix"] = "JGDZMX"          ← 服务端用它拼请求 IV（"-p9B[~PnPs"+头值）
```

## 六、关键踩坑清单（每条都真实踩过）

| # | 坑 | 现象 | 正解 |
|---|---|---|---|
| 1 | **裸 urllib 不走客户端补丁** | 分类有、列表全空 | 内联 `_SSL_CTX` + `_vbox_opener` + `_vbox_host` |
| 2 | opener 在 `__init__` 建 | 注入属性还没设好，读不到代理 | 改为**每次请求构建** |
| 3 | git schannel 过代理 | `failed to receive handshake` | `-c http.sslBackend=openssl` |
| 4 | GCM 等图形认证 | push 无输出卡死 | `-c credential.helper=` |
| 5 | PowerShell here-string 吃引号 | Python 语法错 / git pathspec 错 | 改写成 .py 文件执行 |
| 6 | commit message 含中文括号 | `did not match any file(s)` | `git commit -F 文件` |
| 7 | `.format()` 里的 `{}` | IndexError | 模板内转义成 `{{}}` |
| 8 | 生成器锚点误命中 | `class Spider(_B)` 混入产物 | 精确锚点（`rindex` 定位） |
| 9 | mmmh 配置 JSON | `Extra data` | `raw_decode` 只取首个对象 |
| 10 | mmmh 播放 500 | 缺参数 | 用 `mmMhAnim` 模板带 `host`/`chain`/`encrypt`/`token` |
| 11 | mdtv timestamp | 用秒不通过 | **毫秒**（`_getCurrentMicros()/1000`） |
| 12 | mdtv 密钥 | 用 16B key 被拒 | **32B `Vq234z…`（AES-256）** |
| 13 | mdtv secret | 借用 aijav 的 | 自己的 `&m}q%ea6:…` |
| 14 | 418 当失败 | hsck 整站空 | 恒返 418 但 body 有效，不能按 status 判 |
| 15 | 注入域名覆盖内置 | 用户设错域名整站打不开 | 内置优先、注入仅回退 |
| 16 | `#FE` 当魔数剥离 | hjsq 图片解出乱码 | 全长 `%4==0`，不剥才对 |
| 17 | 字母表当简单替换 | hjsq 图片无魔数 | 表**被重排过**，必须查索引 |
| 18 | `tag` 传中文名 | kpsp 返回基线数据 | 必须传 tag id（判据看 total） |
| 19 | `x-data` 当响应头 | kpsp 以为没加密 | 在**响应体 JSON 里** |
| 20 | mw 封面优先级 | 搜索页 0 条 | 搜索页/详情页真图在 `data-original` |
| 21 | mdtv 漏发 `suffix` 头 | 恒 `1002 参数错误`（响应却能解密） | IV 由「固定前缀 + suffix 头」拼成，头不发 → 请求体解不开。**错误码 1002 不代表参数错** |
| 22 | blutter 字符串转义当原文 | secret 多一个 `\` → `1001 签名错误` | 关键常量一律回 `libapp.so` 取原始字节（`re.finditer` 打 ±40 字节），别抄 asm 注释 |
| 23 | 拿泛化错误码当「参数名不对」 | mdtv 1002 / aijav 999 都曾让人穷举参数 | 先确认「这一层是否被服务端读进去了」：错误码**变了**说明前一刀切对了。aijav 里 `999=路由不存在`、`2000=需登录`、`3001=业务缺参` |
| 24 | 详情参数名想当然 | aijav 传 `id` → 3001 视频不存在 | 参数名看 asm 的 map 字面量：aijav 是 `vid`，mdtv 是 `channel|tags`。空参试探也常能逼出必填名 |
