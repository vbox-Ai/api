## 4. P0 做到了什么 / 没做什么

**已实现**

- 两个平台条目（video / comic），`defaultHosts` = `x99dh.net` + `x99dh.lat`；
- 入口域名竞速：读 `_vbox_effective_hosts`，失败回退快照里的入口；
- 平台 tab：视频 26、漫画 3，顺序与导航一致；
- 二级 chips：分类（能扫到的平台）+ 线路（自动 / 线路 N）；
- 线路优选：600s 缓存、3 条一批接力、死亡冷却 30 分钟、12s 预算；
- 分类扫描：maccms 读 `/enter` 页解析（321AV 3 个、rouAV 6 个、黄色仓库 5 个、爱漫岛 6 个），
  MissAV / 18av 用静态表（7 个）；
- 生成器 + 仓库接线（welfare_platforms / all_sources）+ 本地校验全绿。

**未实现（按计划留给后续）**

- P1：`maccms` 适配器的列表 / 详情 / 播放（现在 `categoryContent` 返回空列表）；
- P2：`missav` 适配器；
- P3：`comic` 适配器（`manga://`）；
- 运行期快照刷新（`NAV_TTL` 已留常量，P1 时接上）。

## 5. 已知问题 / 注意

1. `x99dh.net` 在本机会被 SNI 重置，`.lat` 正常；App 侧两个域名都试，谁通用谁。
2. 301 之外的 500 页面在这些站很常见（321AV 等），所以判定用「body 特征」，不看状态码。
3. 部分平台（SuperPorn、XVIDEOS 等）本次全部线路异常，tab 仍会显示，点进去是空列表 ——
   这是预期行为，等 P1/P4 或换域名后自然恢复。
4. 生成的蜘蛛是**单文件自包含**（含快照），不要手动改；改模板后重新生成。
